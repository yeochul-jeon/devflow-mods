# devflow-mods (stable)

이 branch 는 릴리즈된 버전의 플러그인 목록만 담습니다. 각 mod 는 마지막 릴리즈 태그(`<mod>--v<버전>`)를 가리킵니다.

```bash
claude plugin marketplace add yeochul-jeon/devflow-mods#stable
claude plugin install team-board@devflow-mods
```

설명·소스·변경 내역은 [main](https://github.com/yeochul-jeon/devflow-mods) 과 [Releases](https://github.com/yeochul-jeon/devflow-mods/releases) 에 있습니다.
