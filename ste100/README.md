# ste100

절차, 지시, 결정 항목을 읽는 사람이 잘못 읽지 않게 씁니다. 자동 스킬 `write-unambiguous` 하나가 들어 있습니다.

- 읽는 사람이 글을 보고 그대로 실행하거나 결정할 때 적용합니다. 예: 런북, 인계할 일, 사용자가 칠 명령, 고를 선택지.
- "STE", "ASD-STE100", "절차로", "순서대로", "오해 없게" 같은 말에도 적용합니다.
- 코드 수정과 짧은 사실 답변에는 적용하지 않습니다.

```bash
claude plugin marketplace add yeochul-jeon/devflow-mods
claude plugin install ste100@devflow-mods
```

이럴 때: 새벽 당직자에게 넘길 롤백 절차를 받는데, 한 문장에 행동이 여러 개 섞여 있어 순서를 놓칠 것 같을 때.

## 규칙

ASD-STE100 은 항공기 정비 문서용 영어 작성 규격입니다. Andrej Karpathy 는 LLM 에게 ASD-STE100 으로 설명하게 하면 읽기 쉽다고 했습니다. 규격이 엄격하면 "80% 수준" 으로 완화한다고 했습니다. 이 스킬은 그 80% 를 한국어로 옮긴 것입니다.

지킵니다:
- 한 문장에 지시나 사실 하나만 씁니다.
- 능동태로 씁니다.
- 조건을 문장 앞에 씁니다. "X 이면 Y 하세요."
- 같은 대상은 같은 이름으로 부릅니다.
- 명사를 3개 넘게 잇지 않습니다.
- 3개 이상이면 세로 목록으로 씁니다.
- 전문용어, 식별자, 명령은 그대로 씁니다.
- 비유와 꾸밈말을 쓰지 않습니다.
- 한 문장은 25어절 이내로 씁니다.

풉니다:
- 승인 어휘 사전을 쓰지 않습니다.
- 단계 뒤에 짧은 이유 한 문장을 허용합니다.

```
전: 필요한 설정 변경 후 시스템 재시작을 진행해주세요.
후: 자동 저장이 꺼져 있으면 켜세요. 설정을 저장하세요. 프로그램을 다시 시작하세요.
```

## eli12 와 다른 점

| | eli12 `explain-simply` | ste100 `write-unambiguous` |
|---|---|---|
| 목표 | 처음 보는 개념을 이해시킵니다 | 읽은 사람이 그대로 실행하거나 결정하게 합니다 |
| 수단 | 일상 비유와 텍스트 그림 | 비유 없이 문장 규칙과 세로 목록 |
| 트리거 말 | "쉽게", "12살", "그림으로" | "STE", "절차로", "순서대로", "오해 없게" |

두 스킬은 한 부분에 함께 쓰지 않습니다. "쉽게" 를 말하면 eli12 를 따릅니다.

## 알아둘 것

- **규격 원문과 대조하지 않았습니다.** 규칙은 Karpathy 의 팁, 한국어 2차 정리, team-board 의 ASD-STE100 탭 규칙에서 왔습니다. 그래서 "ASD-STE100 준수" 가 아니라 "ASD-STE100 에서 착안" 이라고 부릅니다.
- 25어절은 team-board 가 정한 값입니다. 규격의 한도는 영어 단어 기준입니다.
- 명료한 문장과 맞는 사실은 다른 검사입니다. 스킬은 원문의 수치, 조건, 예외를 지우지 말라고 지시하지만, 사실 검증은 하지 않습니다.
- 비용: 별도 모델 호출이 없습니다. 스킬이 발동하면 스킬 본문이 대화에 들어갑니다.
- 효과는 아직 확인하지 못했습니다. `claude plugin eval` 실측(2026-10-25, 케이스마다 3회, judge 는 Haiku)에서 트리거는 기대대로였습니다(양성 2케이스 9/9 발동, 음성 3/3 미발동). 문체 점수는 스킬이 없을 때와 차이가 없었습니다: 롤백 절차 2/3 대 2/3, rebase 충돌 3/3 대 2/3(rebase 충돌은 "-고" 규칙을 넣기 전 SKILL 로 잰 값). 스킬이 없는 쪽도 사용자 설정(전역 CLAUDE.md, 설치한 mod)을 불러왔을 수 있어 깨끗한 기준선인지 확인하지 못했습니다. 같은 답을 judge 에 다시 넣으면 판정이 바뀔 만큼 judge 변동이 큽니다(한 답이 FAIL 2표 → 재채점 PASS 3표).

## 개발

```bash
claude plugin validate ./ste100
claude plugin eval ./ste100   # evals/ 의 스킬 케이스 3개
```
