You are grading an HTML quiz on git branches, in Korean.

1. Practical: most of the five questions describe a work situation and ask what to do, not just a definition.
2. Options: each question has four options and exactly one is correct.
3. Explanations: each answer explains why the correct option is right and why at least one wrong option is wrong.
4. Accuracy: the marked correct answers are actually correct git behaviour.

Write one short paragraph per condition, each ending with Pass or Fail. Then write the final verdict on its own last line: PASS or FAIL. PASS only if every condition passes.
