# look-back

`/lookback` 을 입력하면 오늘·어제·7일·30일·올해 동안 한 일을 옆 패널에 보여 줍니다. 맨 위 "한눈에" 칸(Work Report)은 숫자와 차트로, 그 아래는 프로젝트별로 Claude에게 보낸 요청, 내린 결정(질문 → 답), 그 저장소의 커밋을 보여 줍니다.

```
[ 오늘 ] [ 어제 ] [ 7일 ] [ 30일 ]
돌아보기 · 2026-10-18
요청 2 · Claude 작업 27초 · 결정 1 · 커밋 2 · 프로젝트 1

shop 요청 2 · 27초 · 결정 1 · 커밋 2 · 토큰 40.6만 [ 요약 ]
  fe8aa63 init shop
  6ed5ded add cart add_item
  10/18 20:41 ? qty 가 0 이하이면 ValueError 를 낼까요? → 네, ValueError 로 해 주세요
  10/18 20:34 ✓ cart.py 에 add_item(cart, name, qty) 함수를 만들고 git add…
  10/18 20:53 ■ README.md 에 cart.py 사용 예시 섹션을 길게 써 줘  6초
```

- 여러 세션에서 여러 프로젝트를 동시에 진행한 뒤 "무엇을 했나"를 돌아보려고 만들었습니다.
- 다른 mod가 없어도 혼자 동작합니다.

```bash
claude plugin marketplace add yeochul-jeon/devflow-mods
claude plugin install look-back@devflow-mods
```

## 동작

- 기록: 대화형 세션에서 사람이 보낸 요청마다 한 줄을 남깁니다. 담는 것은 요청 글(200자), 프로젝트(저장소 루트), 보낸 시각, 결과(✓ 답함, ■ 중단, ✗ 오류), Claude가 일한 시간, 토큰, 고친 파일(Edit, Write, NotebookEdit), 종류, 모델(0.3.0부터)입니다.
- 기록하지 않는 것: 슬래시 명령, 작업 알림, 다른 세션이 보낸 메시지, 플러그인이 보낸 프롬프트, 서브에이전트, `claude -p` 같은 비대화형 세션.
- 저장: `~/.claude/look-back/<날짜>/<세션>.json`. 세션마다 자기 파일만 씁니다. 날짜는 요청을 보낸 시각의 시스템 시간대 날짜입니다(자정을 넘겨 끝나도 보낸 날).
- 보기: `/lookback [오늘|어제|7일|30일|올해]` (기본 오늘). 패널 위 버튼으로 기간을 바꿉니다. 프로젝트마다 그 기간의 `git log` 커밋 제목을 함께 보여 줍니다(최근 커밋 8개, 최근 요청 12개).
- 결정: [team-board](../team-board/README.md)가 세션마다 남긴 결정 기록(질문 → 답)을 기간으로 걸러 `? 질문 → 답` 줄로 보여 줍니다. look-back 은 결정을 따로 감지하지 않습니다. team-board 가 없으면 결정 줄이 없습니다. look-back 을 설치하기 전 세션의 결정도 보입니다(요청 기록이 없는 프로젝트는 결정과 커밋만).
- `[요약]` 버튼을 누르면 그 프로젝트의 요청, 결정, 커밋 제목을 Haiku 에 한 번 보내 3줄 이하로 요약합니다. 요청·커밋의 낱말을 그대로 쓰게 합니다.
- Esc로 패널을 닫습니다.

## 한눈에 (Work Report)

<img src="../docs/images/work-report.webp" alt="한눈에 칸: 타일 세 개, 어디에 썼나, 누가 했나, 최근 7일 차트" width="560">

- 타일: **아낀 시간**(추정) · **끝낸 요청**(답한 요청 수) · **Claude 작업**(턴 시간 합, 실측). 좁은 패널에서는 타일이 3 → 2 → 1칸으로 줄을 바꾸고, 숫자가 칸보다 넓으면 굵은 글자 한 줄로 씁니다.
- 어디에 썼나: 요청 종류별 막대·건수·추정 시간. 종류는 그 요청에서 메인 Claude가 쓴 도구로 정하고, 앞 것이 이깁니다.

| 종류 | 도구 | 아낀 시간 기본값 |
|---|---|---|
| 코드 수정 | Edit · Write · NotebookEdit (성공한 것) | 20분 |
| 실행 | Bash (실패한 명령 포함) | 10분 |
| 조사 | Read · Grep · Glob · WebSearch · WebFetch · Agent, 읽기만 하는 Bash (`cat` · `grep` · `sed -n` · `git log` 등) | 15분 |
| 대화 | 도구 없음 | 5분 |

거부된 도구는 세지 않습니다. Bash 는 이어 붙인 명령이 모두 읽기만 할 때만 조사입니다. 하나라도 다른 명령이나 파일로 쓰는 리다이렉트(`> f`)가 섞이면 실행입니다. 판정은 team-board 의 숨은 실패 감지에 쓰는 규칙과 같습니다.

- 누가 했나: 모델별 막대·건수 (메인 요청의 모델).
- 차트: 3줄 막대. 오늘·어제·7일은 최근 7일(요일), 30일은 날짜, 올해는 1~12월. 오늘·이번 달은 노랑. 아래 한 줄: 최근 7일 아낀 시간과 연속 일수, 또는 가장 많은 날·달과 일한 날 수.
- 0.3.0 전 기록은 종류·모델이 없어 "기록 전"으로 보이고, 아낀 시간에 넣지 않습니다. 막대 길이는 "기록 전"을 빼고 잽니다.
- 아낀 시간은 추정입니다. 요청 하나를 몇 분으로 칠지는 `claude plugin configure look-back@devflow-mods` 에서 종류마다 바꿉니다. 금액은 보여 주지 않습니다.
- 켜기·끄기: `/lookback report off` / `on`. 기본은 켜짐이고 다음 세션에도 유지합니다. 꺼도 종류·모델 기록은 계속하므로, 다시 켜면 지난 기간도 바로 보입니다.
- 디자인은 Tristen O'Brien 의 Work Report mod(영상 "5 MORE Claude Code MODS You Need")를 참고했습니다. 코드는 새로 썼습니다.

## 비용

- 기록과 보기는 모델을 부르지 않고 프롬프트도 바꾸지 않습니다. 2026-10-18 `claude -p` 비교에서 첫 요청 입력이 빈 mod 와 같았습니다(16,839 토큰, 두 번째부터 전부 캐시 읽기).
- `[요약]` 을 누를 때만 Haiku 1회.
- 파일 쓰기는 요청마다 2번(보낼 때, 끝날 때)입니다.

## 알아둘 것

- 설치하기 전의 요청은 없습니다. 커밋은 `git log` 라서 설치 전 것도 보입니다(그 기간에 요청 기록이 있는 프로젝트만).
- 시간은 Claude가 일한 시간(턴 시간)입니다. 권한 확인을 기다린 시간은 들어가지 않습니다.
- Claude가 일하는 중에 보낸 요청은 진행 중인 턴 안으로 전달돼 자기 턴이 없습니다. 이 요청은 `·`(결과 모름)로 남고 시간이 붙지 않습니다.
- 토큰은 요청마다 입력·출력·캐시 읽기·캐시 쓰기를 더한 값이라 크게 보입니다. 비용 추정이 아닙니다.
- 요청 글에서 token·password 같은 변수 값, 인증 헤더, URL 비밀번호, 알려진 토큰 꼴을 `***` 로 가립니다. 기록은 내 컴퓨터에만 있습니다. 지우려면 `~/.claude/look-back` 을 지우세요.
- team-board 는 세션마다 결정을 최근 20개만 둡니다. 결정이 아주 많은 세션은 앞쪽 결정이 빠집니다.
- Claude Code 2.1.302 에서 시험했습니다.
